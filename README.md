### ⚡ About Me

I'm a CSE student who spends more time in the terminal than in lecture halls. I care about **how things actually work** — how a version control system stores objects on disk, how a kernel driver talks to an embedded controller, how a socket pushes encrypted bytes across a network. Instead of stopping at "it works," I like to rebuild the primitive myself: a Git clone, a transfer protocol, an environment validator, a deployment platform.

I haven't shipped an open-source PR to someone else's repo yet — but I've been busy building complete systems of my own, end to end, often reverse-engineering the hard parts along the way. This profile is that journey so far.

- 🔭 Currently deep in **backend engineering, systems programming, and Linux internals**
- 🐳 Comfortable containerizing and shipping services with **Docker & Podman**
- 🧠 Obsessed with **networking, databases**
- 📊 Dabbling in **machine learning** on the side — data pipelines, models, and evaluation

### 🚀 Projects

#### 🔍 [envix](https://github.com/yourusername/envix)
**A CLI environment validator that ends "it works on my machine" — for good.**
Written in Rust. Parses YAML manifests, probes host binaries, extracts semantic versions via regex, and evaluates them against declared constraints before you ever hit `build`.
`Rust` · `YAML` · `Regex` · `Semver`

#### 🔐 porthole
**An encrypted file/directory transfer CLI, built for speed and zero trust.**
Uses SPAKE2 password-authenticated key exchange and raw socket streaming for high-speed transfers. Cross-compiled to run natively on both Linux and Windows.
`Rust` · `SPAKE2` · `Socket Programming` · `Cross-Compilation`

#### 🗂️ .myvc
**A Git-like version control system, built from scratch in C.**
Implements repository initialization, staging, and content-addressable object storage backed by SHA-1 hashing via OpenSSL — no libgit2, no shortcuts.
`C` · `OpenSSL` · `SHA-1` · `Content-Addressable Storage`


#### 🌌 apod_cli
**A Rust CLI that brings NASA's Astronomy Picture of the Day to your terminal.**
Async, typed, and fast — fetches image metadata straight from NASA's public API.
`Rust` · `clap` · `reqwest` · `serde` · `tokio`
